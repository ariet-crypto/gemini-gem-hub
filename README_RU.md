# Gemini Gem Hub — стартовый проект

PWA для iPhone с отдельными Gem-ботами. Созданные Gem и переписки сохраняются локально в браузере. Инструкции Gem отправляются на сервер вместе с сообщениями. Это не импортирует оригинальные Gem из Google-аккаунта.

## Развёртывание
Нужен хостинг, поддерживающий Node.js 20+ и HTTPS.
1. Загрузите файлы проекта в приватный репозиторий или файловое пространство хостинга.
2. Установите секретную переменную окружения `GEMINI_API_KEY` в настройках хостинга. Не помещайте ключ в HTML, репозиторий или сообщения.
3. Запустите команду `npm start`.
4. Откройте выданный HTTPS-адрес в Safari.
5. Safari → Поделиться → На экран «Домой».

API может иметь ограничения по квотам и тарифам Google. Перед использованием проверьте условия в Google AI Studio. Для публичного использования добавьте авторизацию, ограничение запросов и защиту от злоупотреблений.
